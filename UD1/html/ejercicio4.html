Ejercicio 4

  • URL

Una URL es la dirección única que se escribe en un navegador para encontrar un recurso o página en internet.

  • HTTP

HTTP (por sus siglas en inglés, Hypertext Transfer Protocol o Protocolo de Transferencia de Hipertexto) es el conjunto de reglas que permite la comunicación entre un navegador web y un servidor en internet.

  • TCP/IP

TCP/IP es el conjunto de reglas básicas que permite que las computadoras y otros dispositivos se comuniquen y compartan datos en Internet.

  • Internet

Internet es una red mundial descentralizada de computadoras y dispositivos interconectados que comparten información a gran escala.

  • W3C

El W3C o World Wide Web Consortium es una organización internacional que crea las normas y reglas para que internet funcione igual en todo el mundo.

  • HTML

El Lenguaje de Marcado de Hipertexto (HTML) es el código estándar que se usa para crear y estructurar las páginas web.
